# Assignment 1: What Happens Between Typing a URL and Seeing the Page?

When we type a URL (Uniform Resource Locator) into a web browser and press Enter, several steps occur before the webpage appears on the screen.

**Step 1: Enter the URL:** The user enters a website address, such as www.google.com, into the browser.

**Step 2: DNS Lookup:** The Domain Name System (DNS) converts the domain name into an IP address.

**Step 3: Establish Connection:** The browser connects to the web server. For HTTPS websites, a secure connection is established.

**Step 4: Send Request:** The browser sends an HTTP request to the server for the webpage.

**Step 5: Receive Response:** The server sends an HTTP response containing HTML, CSS, JavaScript, and other resources.

**Step 6: Render the Page:** The browser processes these files, creates the webpage layout, applies styling, and runs JavaScript.

**Conclusion:** Finally, the browser displays the webpage on the screen, allowing the user to interact with it.
